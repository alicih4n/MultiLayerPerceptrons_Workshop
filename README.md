## Project Overview
This repository contains the completion of the Multi Layer Perceptrons Workshop assignment. It includes:
1. **Framework Comparison:** A detailed comparative analysis of deep learning frameworks (Keras, PyTorch, and TensorFlow) focusing on speed, accuracy, and useability for standard classification tasks like MNIST.
2. **NumPy MLP Implementation:** A completely from-scratch implementation of a 3-layer Multi-Layer Perceptron using purely NumPy. This includes forward propagation, loss calculation (binary cross-entropy), backpropagation via chain rule, and parameter updates to solve a non-linear XOR dataset. It provides deep reflection on learning dynamics, weight initialization, and activation functions.

## Setup Instructions
To set up the project locally:
1. Clone the repository: `git clone https://github.com/alicih4n/MultiLayerPerceptrons_Workshop.git`
2. Navigate to the project directory: `cd MultiLayerPerceptrons_Workshop`
3. Install required dependencies: `pip install -r requirements.txt` (or if you don't have one, `pip install numpy matplotlib jupyter`)

## How to Run
1. Start the Jupyter Notebook server: `jupyter notebook`
2. Open `MultiLayerPerceptrons_Workshop.ipynb`.
3. Execute the cells sequentially to observe the framework implementations, the framework comparison, and our custom from-scratch NumPy XOR implementation.
