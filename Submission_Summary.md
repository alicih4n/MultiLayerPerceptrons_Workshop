## Executive Summary
This submission finalizes the Multi Layer Perceptrons Workshop with a thorough comparative study of deep learning frameworks like Keras, PyTorch, and TensorFlow for image classification, determining Keras to be the most efficient for standard problems like MNIST. In addition, the project successfully implements a 3-layer neural network from scratch using purely NumPy to solve the non-linear XOR problem, explicitly computing forward and backpropagation. Through this implementation, we observed key deep learning dynamics, noting that correct weight initialization and the choice of ReLU activation in hidden layers are imperative for rapid convergence and avoiding vanishing gradient issues.
